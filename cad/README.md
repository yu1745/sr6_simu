# SR6 光轴连杆改装

当前主文件：`sr6_mini_complete.stp`，共72个实体。来源为 `../../sr6_mini.stp`，原件不覆盖。
`sr6_mini_updated_parts.stp` 保留为补齐左侧俯仰支链之前的版本。
上一版 `sr6_mini_D10_L210_M6.stp` 作为替换底座和俯仰臂之前的装配保留。

## 用户提供的替换件

使用 Downloads 中的 `俯仰二级摇臂.zip` 和 `U_body_8108.zip`，解压副本在 `inputs/`。
用新STEP直接替换实体49（现有唯一俯仰二级摇臂）和实体1（电机底座）。
两件仅旋转和平移，比例均为1；没有拉伸或改造新零件来掩盖尺寸差。
所指Linux截图路径在本Windows环境不可读，零件对应关系由压缩包名称及装配结构匹配。

| 比较项目 | 旧件/旧装配 mm | 新件/新装配 mm |
|---|---:|---:|
| 相邻电机轴距 | 95 | 95 |
| 电机中心距底面高度 | 59 | 51.5 |
| 主电机安装面外宽 | 108 | 118 |
| 俯仰电机安装面外宽 | 108 | 84 |
| 电机底座圆形开口直径 | 80 | 67 |
| 俯仰臂两端孔沿孔轴方向的间隔 | 219 | 199.9 |
| 俯仰臂两端孔轴横向错位 | 63 | 76.4 |
| 俯仰臂端孔直径 | 5 | 6 |
| 俯仰连杆含鱼眼球心距 | 273.5 | 258.6 |

电机与一级摇臂随新底座安装面定位：整体下移7.5 mm；主电机每侧外移5 mm，
俯仰电机每侧内移12 mm。四根光轴按原258 mm长度重新闭合。
俯仰鱼眼沿用旧装配约22.5/24.6 mm的球心到端板中面距离，重新对准新臂的端孔；
M4摇臂装配角调整为约15.63°。接收器位置保持不变，俯仰连接螺栓过孔按Ø6.5建模。
这些是装配尺寸差异，不代表现有实物电机的全部螺孔、螺栓和动态间隙已验收。
详细安装变换与测量结果记录在 `replacement-fit.json`。

左侧M3支链已补齐：镜像一级摇臂、二级摇臂和两端鱼眼（实体58–63），
与右侧连杆保持相同258.570 mm球心距。底座中心面Z=-54，接收器中心面Z=-62.586，
相差约8.586 mm，因此左侧按现有接收器孔位定位，装配角约19.10°，右侧约15.63°。
零件尺寸保持一致，两端均闭合连接。

## 装配尺寸

| 项目 | 参数 |
|---|---|
| 四根二级连杆 | Ø10 × 210 mm 光轴 |
| 光轴两端螺纹 | M6×1 右旋，牙深12 mm，模型底孔深14 mm |
| 八只鱼眼 | POS6 尺寸：孔Ø6、球Ø12.7、内圈宽9、外壳宽6.75、头部Ø18 mm |
| 鱼眼螺杆 | 球心至端部36 mm，外螺纹长22 mm |
| 旋入长度 | 每端12 mm，外露螺纹10 mm |
| 连杆球心距 | 210 + 2 × (36 − 12) = **258 mm** |
| 四个隔位螺母 | DIN934 M6，厚5 mm、对边10 mm |
| 两套叠放鱼眼贯穿紧固件 | 全牙 M6×40 杯头内六角螺栓 + M6锁紧螺母 |
| 杯头及内六角 | 头径10、头高6、内六角对边5、建模槽深3 mm |
| 接收器叠放 | 接收器 → 螺母5 → 鱼眼9 → 螺母5 → 鱼眼9 |
| 同侧球心错层 | **14 mm**，靠内为lower连杆、靠外为upper连杆 |
| 连接安装孔 | 接收器主支链孔、四摇臂端孔由Ø5扩到Ø6.5 mm |

按用户要求，光轴端孔、鱼眼螺杆和螺母均不画螺旋牙型，用圆柱包络简化表示，
M6×1与牙深12 mm保留为尺寸定义。端孔模型直径6.05 mm仅是配合包络，
不是攻丝底孔尺寸；名义攻丝底孔Ø5 mm。盲孔额外2 mm为底孔余量，不计入12 mm牙深。
鱼眼尺寸参考IKO POS6目录，复用源模型符合这些尺寸的头部，
不是厂商认证的原版下载CAD。

四根光轴均为独立刚体，球心与安装点通过改变摇臂角度闭合，零件无缩放。
左右鱼眼沿各自接收器孔轴叠放；原模型右侧偏离孔轴的鱼眼已经回到同一孔轴。
叠放鱼眼左右各用一根M6×40贯穿螺栓：杯头朝外，接收器内侧用M6螺母锁紧。
夹持叠层为32 mm，加5 mm锁紧螺母后，螺杆端部余量约3 mm。
使用全牙规格以适应中间隔位螺母的位置；仅保留圆柱螺杆，不建螺纹牙型。

## 运动与检查范围

网页STEP装配随输入位姿运动，按实际球心和长度独立求解摇臂。
R0只旋转输出夹具；M3对称支链已经补齐，全部六组支链均绑定运动。
新增贯穿螺栓和锁紧螺母随接收器整体运动。
STEP模式使用实测尺寸独立正逆解，面板M1–M6为相对装配零位的实际摇臂角增量。固件骨架模式仍使用262 mm等原参数和固件逻辑角。切换模式时回到各自零位。
运动范围超出CAD可达域时保留上一CAD画面，并显示原因。

已检查修改后实体有效、四主连杆258 mm球心距、简化螺杆配合，以及鱼眼/螺母/接收器和
鱼眼/摇臂的指定接口在本装配位姿无体积交叠。未完成全部零件、全部运动范围的干涉检查。
源文件电机实体2、4、6、8、10、12、39本身存在B-rep有效性问题；它们按原样保留。

## 本次补齐与朝向

接收器四个挂点均有杯头内六角螺栓：两个叠放主挂点用M6×40，两个俯仰挂点用M6×20，内侧各配一个5 mm厚M6螺母。俯仰挂点夹持厚度13 mm，穿过螺母后余量2 mm。
俯仰二级摇臂本体端孔按直接攻牙处理，鱼眼螺杆直接旋入，不另外增加螺栓或螺母，不画牙型。
网页恢复最初方位角，再绕水平轴翻转90°：电机底座大平面垂直地面，俯仰端朝上；整机最低点落在地面网格。STEP装配坐标保留。
