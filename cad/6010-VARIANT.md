# 6010 与 8108 并存版本

6010 输出：`sr6_6010_complete.stp`，78 个实体。模拟器左侧通过「8108 版本 / 6010 版本」标签页切换；切换会暂停脚本、恢复装配零位，并重新加载相应的 CAD、惯量和碰撞状态。STEP 与惯量下载链接随版本切换。

重建基准是现有 `sr6_mini_complete.stp`。用户提供的桌面 `sr6_minia.stp` 仅用于提取底座及六套 6010-8 电机（每套机体和后盖两件）。原文件的精确副本保存在 `inputs/sr6_minia.stp`，SHA-256 为 `0b0a03361ce7103e976d0441e9780fa6f5c910a5bc8773bc4b769694d9c564c2`。

参考文件坐标转换为模拟器 STEP 坐标：`(X, Y, Z) → (Y + 2.5, Z + 4, X − 54)` mm。这是刚体旋转和平移，缩放为 1。底座底面、中心面及首排轴线用于对齐。

两版底座排距均为 95 mm，轴高约 51.5 mm；12 个 Ø67 安装孔边缘圆心最大差值为 0.00004020 mm。六个电机的输出安装面与现有一级摇臂贴合面的最大差值约 0.00000010 mm。因此无需移动现有 65 个实体或重新定义运动学。六组关节点和零位闭环参数完全沿用 8108。

65 个保留零件的 B-rep 直接复用当前 STEP；网页顶点、索引、名称、质心和包围盒逐项复用当前 JSON。导出后重读 STEP 计算惯量，并检查实体顺序及质心与网页网格一致。两版运动质量约为 1.977659 kg，底部电机及底座为固定组件，不计入现有运动惯量模型；R0 仍使用已有 388 g 实测质量。

参考文件的六个电机机体，以及基准文件的 R0 电机，继承了 OCCT 有效性检查不通过的源几何；记录在 `validation-6010.json`，本次未重塑其内部几何。已验证安装轴线、安装面和机构闭环；此记录不等于整机全行程干涉验收。网页仍按现有 33 个零件范围检查干涉。

复现：

```powershell
conda create -n sr6_cad -c conda-forge python=3.11 cadquery vtk
npm run cad:6010
npm run test:cad-variants
npm run build
```

重建脚本：`scripts/build-6010.py`；装配来源及变换：`assembly-spec-6010.json`；几何检查：`validation-6010.json`；质量数据说明：`../docs/MASS-PROPERTIES-6010.md`。

验证包括两版各 12 组独立自由度运动、不可达回退、零位复位；13 个位姿下两版解与动力学力矩一致；现有装配分支回归通过。浏览器检查往返标签切换、运动后复位、快速切换时异步加载取消及两种下载链接。
