# 干涉性能实测 · 2026-10-12

Ryzen 7 5700X（8 核 / 16 线程）；Chromium headless，本地 Vite 页面，1600×1000。原始 WooHanKyung 脚本组，默认轴范围，虚拟杆关闭。每配置三轮。

| 毫秒，三轮中位数 | JS 单 Worker | JS 四 Worker | WASM 四 Worker，排除电机 |
|---|---:|---:|---:|
| 8.8 秒首次 | 730 | 378 | 133 |
| 10 秒 | 511 | 291 | 50 |
| 15 秒 | 410 | 169 | 33 |
| 20 秒 | 738 | 335 | 200 |
| 8.8 秒再次 | 602 | 270 | 128 |
| 空格暂停后等待 | 798.8 | 433.2 | 164.5 |

从 8.8 秒播放约 5 秒后按 Space，暂停位置约 13.8–13.9 秒，非完全同一帧。等待包括旧批次收尾与当前批次。检测耗时是线程批次墙钟时间，不含特征边显示构建。

RAF 平均 16.68 ms、P95 16.8 ms，仅是回调节奏，不等于 GPU 实际帧率。

采用 Manifold 3.5.4，每个 Worker 独立 WASM 实例、多核并行，非共享内存 pthread。排除电机/端盖 ID 2–13、39、40（14 件）；底座与运动件检测保留。剩余 58 件均可构建 Manifold。

核对通过：初始姿态与五次 seek 的干涉零件对集合在 JS 和 WASM 中完全一致（不只是数量）；未验证全行程交集体积精度。
