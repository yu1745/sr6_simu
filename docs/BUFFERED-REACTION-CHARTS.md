# Buffered 轨迹与六轴底座反力曲线

实现依据为本机 `Desktop/MultiFunPlayer/Source/MultiFunPlayer/OutputTarget/TCodeBuffered/TCodeBufferedPlan.cs` 的 `TurningPoints`、`Smooth` 及长段分割逻辑，并参考该仓库 `Docs/TCode04-redesign.zh-CN.md`。协议版本是 TCode 0.4（本地代码称 Buffered Update）。

脚本读取、轴范围、反向、倍率及分组规则继续使用模拟器原有设置。播放时先按 1% 回差提取转折点，保留开头显式静止段；同向中间采样点不再逐点作线性插值。每对相邻节点之间使用：

`s(u) = 35u^4 - 84u^5 + 70u^6 - 20u^7`，`u = (t - t0) / T`。

七次多项式由起终点位置及两端一、二、三阶导数为零的八个条件唯一确定。每个输入轴的反向节点速度、加速度、加加速度均为零；这不是对每个电机角度直接作七次插值。各输入轴再经过杆尖补偿和机构逆解获得实际装配运动。多轴转折点不同时，某一轴换向不代表整个机构同时静止。

与 MFP 一样，超过 60 秒实际播放时间的段先均分节点，再作分段七次插值。初始延迟前保持首位置，末尾保持末位置。倍率影响真实时间导数：速度、加速度和加加速度分别按倍率的一、二、三次方变化。

这是本地模拟器对轨迹曲线的复用，没有建立串口会话，也没有模拟设备 ACK、预装载和限值协商；没有设备限值时不假设自动缩幅。位置保留浮点精度，不引入线上协议整数编码。中途拖动后从原轨迹位置继续，不执行硬件的重新定位预段。

CAD 脚本动力学使用参考轨迹在当前时刻前后 ±1 ms、±2 ms 的位姿，分别经过相同补偿与逆解，再对刚体质心和旋转作五点差分，得到真实时间的线加速度、角速度、角加速度。此路径不使用原来的 10 Hz 低通和 ±20 m/s² 截断，因此不会人为滞后或削平参考轨迹的反力峰值。端点参考导数精确为零，几何数值微分结果存在微小浮点误差。手动操作清除动态项，旧固件骨架路径保留原估计器。

底部显示 Fx、Fy、Fz、Mx、My、Mz 六张平铺曲线，单位分别为 N 和 N·m，坐标为 STEP XYZ。力矩参考点仍是固定底座钣金质心。图中是运动部件及额外负载对底座的总反力，包含重力和惯性，所以换向时动态项归零不意味着总读数为零。

六图共用脚本时间轴，保留最近 10 秒，纵轴分别自适应。采样沿用显示姿态及动力学快照；不以墙上时间推动横轴。空格切换暂停/继续，长按的重复键事件被忽略；暂停拒绝新增采样，并保留曲线、数值、纵轴范围和横轴。拖动、脚本切换、变速和循环回绕开启新的历史段，过期异步帧不接入新图。屏幕采样频率有限，短时峰值仍可能漏采。

验证：`node scripts/test-buffered-playback.mjs` 覆盖 MFP 原有转折点样例、端点三阶导数、倍率、长段、参考动力学、暂停及旧帧过滤；现有刚体动力学与碰撞快照回归通过。浏览器完成实际脚本播放、六图更新、空格长按冻结以及继续播放验证。
